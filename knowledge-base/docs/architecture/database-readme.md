# Database

The database layer stores all persistent data used by the TITAN Core Platform.

Primary Database

PostgreSQL

Future Components

- Redis
- ElasticSearch
- Object Storage

Core Data

- Users
- Organisations
- Roles
- Permissions
- Products
- AI
- Health
- Notifications
- Audit Logs
