# BD-010 - Specification Before Implementation

**Document ID:** BD-010
**Status:** Approved
**Owner:** TITAN Engineering

## Standard

Every material capability must follow:

Requirement -> Specification -> Architecture -> Implementation -> Tests -> Verification -> Sign-off -> Release

Implementation must define scope, acceptance criteria, security and tenant implications, failure behaviour, evidence and explicit non-goals.

No capability is complete solely because code exists.
