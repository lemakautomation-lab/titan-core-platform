This file explains how to transfer TITAN to a new ChatGPT account.

2. Keep the TITAN repository unchanged during the handover.
3. Copy/upload this entire TITAN-CONTINUITY directory to the new ChatGPT account.
4. Give the new account `13-CHATGPT-MASTER-PROMPT.md`.
5. Tell the new account to read the complete package before making code changes.
6. Require the new account to inspect the actual repository.
7. Verify that it identifies Mission 055.1 as complete and Mission 052 as active/incomplete.
8. Verify that it identifies 052-R0 as the current documentation-only checkpoint.
9. Verify that Option B and the ordered R0–R7 closure plan are recorded.
10. Only begin R1 after separate approval.

## DO NOT

Do not ask the new account to reconstruct TITAN from memory.

Do not paste random historical conversations before the continuity package has been read.

Do not allow the new account to reset, clean, stash or bulk-stage the repository.

The new CTO should independently state:

- the current branch;
- `main`, HEAD and origin/main at `482487a661b4778412c176e34339eb1fa1bd8f06`;
- that Mission 054 is complete;

Only after this verification and formal planning approval should implementation continue.
